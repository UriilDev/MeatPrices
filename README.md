### 📦 Instrucțiuni de lansare (RO):
1. Descărcați arhiva ZIP din secțiunea **Releases** (vezi mai sus) și **despachetați-o complet** într-un folder.

# 🚀 Floreni Price Parser & Market Analyzer v1.0 (Версия на русском)

> 📥 **ИНСТРУКЦИЯ ПО СКАЧИВАНИЮ:**
>
> 1. В правой колонке этой страницы найдите блок **Releases** (справа от текста).
> 2. Нажмите на плашку **`Demo MeatPrices`** *(или `Latest`)*.
> 3. В самом низу страницы релиза в блоке **Assets** нажмите на ваш `.zip` архив, чтобы скачать софт.

---

### 📦 Инструкция по запуску (RU):
1. Скачайте ZIP-архив из раздела **Releases** и **обязательно распакуйте его полностью** в отдельную папку.
2. Запустите файл **`Floreni.exe`**.

> ⚠️ **Важно:** Папки `_internal` и `data` должны находиться в одной директории с `Floreni.exe` для корректной работы программы.

---

### 📂 Структура файлов:
- **`Floreni.exe`** — главное приложение.
- **`_internal/`** — зависимости и системные библиотеки.
- **`data/`** — конфигурационные файлы и директория для выгрузки результатов.

---

### ✨ Ключевые возможности:
- Автоматический сбор и структурирование данных по ценам.
- Автономный запуск без необходимости установки Python.
- Быстрый экспорт полученных данных.
