# 🚀 Automated Price Monitoring & Scraping Tool v1.0

Автоматизированный софт для сбора, обработки и анализа цен с веб-ресурсов. Поставляется в виде готового автономного исполняемого файла (`.exe`), не требующего установки окружения Python или дополнительных зависимостей.

---

### 📦 Содержимое архива (`Price_Scraper_v1.0.zip`)
* **`PriceScraper.exe`** — исполняемый файл приложения.
* **`demo_preview.mp4`** — видео-демонстрация работы программы (1.5 мин).
* **`config.json` / `settings`** — конфигурационные файлы и параметры парсинга.
* **`README.txt`** — краткое руководство пользователя.

---

### ✨ Основной функционал
* **Автоматический сбор данных:** Парсинг актуальных цен, наименований и категорий товаров.
* **Автономность:** Полный запуск на любой системе Windows x64 в 1 клик.
* **Обработка ошибок:** Защита от сбоев сети и корректная обработка динамических элементов страниц.
* **Экспорт:** Сохранение собранных данных в структурированные форматы.

---

### 🎥 Видео-демонстрация
Внутри архива приложен файл `demo_preview.mp4` с наглядным обзором интерфейса и процесса сбора данных.
